You will learn what makes an asset reusable, file it in a local library with catalogs, compare Append, Link and a library override and fetch one online Essentials material. Then you build the scatter node by node, steer it with a distance mask, groom a static hair-curve tuft and scatter it as a second layer from the same graph.

Main topics include Pack Resources, import methods, Allow Online Access, Spreadsheet domains, fields versus attributes, Object Info in Original and Relative mode, Distribute Points on Faces, Instance on Points, Join Geometry, Random Value, Rotate Rotation, Geometry Proximity, Map Range, Store Named Attribute, Empty Hair, Interpolate Hair Curves, Set Hair Curve Profile, exposed group inputs, Scatter on Surface and Realize Instances. Recorded in Blender 5.2.2 LTS.

Before you start: this lecture continues the Lumen Field Station from Lecture 7. The files are w08_station_entry, w08_station_work, w08_station_v001 and w08_station_v002 in the blend folder, w08_asset_test beside them, and w08_assets in the assets folder, which holds the stone and the Grass Tuft collection. Keep both folders side by side, then add assets as a local library named LumenCourse with Append, as the video does. Lecture 9 builds a procedural signal display that responds to sound.

Values used in the lesson: stone scaled by 0.35 to 0.27 × 0.23 × 0.30 m, 642 vertices, later flattened to 0.7 in Z (21 cm); terrain 4.4 × 4.4 m, about 19 m²: density 0.5 gives 10 points, density 2 gives 52 stones; scale 0.7 to 1.3; turn 0 to 2*pi; mask 0.1 m to 1, 0.9 m to 0, times density 3; tuft patch radius 10 cm, Add count 3, length 12 cm, interpolation 500 then 5000, strand radius 1.5 mm; grass layer density 8, seed 5.
