ComfyUI-only users follow the same steps and set the ComfyUI models folder in the downloader.

Step by step:

1. ComfyUI: download the latest ComfyUI zip, extract it into your existing ComfyUI folder and choose Replace the files in the destination. Run Windows_Install_Or_Update_ComfyUI.bat; it detects the existing installation and updates it. Then run Windows_Custom_Nodes_Bundles_Installer.bat, enter 100 and confirm, so the custom node bundles are updated too.

2. Models: extract the SwarmUI Model Downloader zip over the old one, overwrite all, start Windows_Start_Download_Models_App.bat and check the download path. With SwarmUI, download into the SwarmUI Models folder. ComfyUI only: paste the path of your ComfyUI models folder, select the ComfyUI folder structure and click Remember Settings. Download a bundle with one click; files you already have are verified, not downloaded again.

3. SwarmUI: run Windows_Install_Or_Update_SwarmUI.bat. It updates SwarmUI and our extensions, stages each update, rolls a failed one back and verifies every extension against the new build.

4. Presets: run Windows_Preset_Delete_Import.bat. It backs up your current presets, deletes them and imports the latest Amazing_SwarmUI_Presets file. Refresh the Presets tab.

Where to extract: the ComfyUI zip goes into your existing ComfyUI installation folder, the one with Windows_Install_Or_Update_ComfyUI.bat. The SwarmUI Model Downloader zip goes into the folder where you installed SwarmUI before, the one with Windows_Install_Or_Update_SwarmUI.bat. Windows Extract All and WinRAR both work; overwrite all files.

The newest presets in this update include Anima, AvatarForever, Krea 2, ERNIE Image, FastH3 Omni and Fibo 2.0. Their models come with the matching bundles of the model downloader.

Keep your own presets: click Import in the Presets tab, choose the latest Amazing_SwarmUI_Presets file and turn on Overwrite existing presets. Presets with the same names are updated and your differently named presets stay. To change one of ours, duplicate it from its menu and rename it, so later updates never overwrite it. Always extract and overwrite all files, so every part is the latest version.

This video is for anyone who uses our ComfyUI or SwarmUI installers and wants the newest models, presets and fixes without reinstalling.
