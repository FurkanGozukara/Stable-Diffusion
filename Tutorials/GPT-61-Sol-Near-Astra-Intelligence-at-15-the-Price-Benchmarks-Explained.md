Release snapshot: September 29, 2026. Standard rates per million tokens: $2 input, $0.10 cached input, $10 output. Cached input is 50% below prior Sol's cached rate and 95% below standard input. Above 272K input tokens, the full request uses $4 input, $0.20 cached input and $15 output. Cache writes and processing modes have separate rates.

The API identifier is gpt-6.1-sol. The release lists Plus, Pro, Business, Enterprise and Edu in ChatGPT Work and Codex; it is not yet in Chat. Ultrafast is upcoming, with announced up-to-8x token-generation speed in Codex; tool waits still affect a whole task.

Published research/API results can differ from ChatGPT because prompts, tools and effort differ. Competitor scores come from public reports. Factuality/safety use selected difficult or adversarial tests. This tutorial did not run benchmarks; compare your own representative task.
