You will learn how to place useful origins, preserve a Mirror seam, control bevels and shading, add thickness with Solidify, use the current Array modifier, compare transform order and linked mesh data, and choose support loops or creases for subdivision.

Main topics include editable Bezier cables, snapping bases and targets, text, proportional editing, Simple Deform, native loop tools, separate courier parts, shoulder origins, pivot choices and an editable Boolean socket. Finish by testing a dimensional revision and reopening the saved station. Recorded with Blender 5.2.2 LTS.
