You will learn how to select vertices, edges and faces; distinguish object transforms from mesh edits; use inset, extrusion, loop cuts, edge slide and bevel; preserve wall thickness; bridge boundaries; and inspect geometry before continuing.

Main topics include Object and Edit Mode, X Ray, Global/Local/Normal orientations, applied scale, reference images, connected shells, separate parts, Merge by Distance, Auto Merge, face orientation, non-manifold selection, dissolve versus delete, and a Bevel modifier preview. Recorded with Blender 5.2.2 LTS.
