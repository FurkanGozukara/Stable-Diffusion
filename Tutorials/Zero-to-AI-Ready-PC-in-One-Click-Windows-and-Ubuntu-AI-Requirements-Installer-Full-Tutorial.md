What it installs on Windows: the latest compatible NVIDIA WHQL driver for GeForce RTX 20-series and newer (checked on every run, never downgraded); Python 3.10 to 3.14 for all users, 3.12 as default; CUDA 12.9 and 13.2 side by side (13.2 default) and cuDNN 9.20, the only cuDNN registered, so PyTorch never mixes two versions; Visual Studio 2022 Build Tools (MSVC, Windows SDK) that keep compiling after Visual Studio updates, the latest Visual C++ runtime and CUDA integration; Git, Node.js 24, .NET 10 SDK for SwarmUI, FFmpeg 9 shared and static; PATH in the right order with your own entries kept, long paths, a 100 GB page file. Ready for torch.compile, Triton and flash-attention, sage-attention, xformers and insightface builds.

On Ubuntu the C++ tools are GCC, Clang, CMake and Ninja, plus Git LFS, uv, free-threaded Python 3.13t and 3.14t and a swap file. With an NVIDIA GPU it installs the newest driver Ubuntu offers and never downgrades it. Ubuntu's own python3 stays as it is.

Windows: put the zip in Downloads (not directly on C:), extract it, right-click Windows_AI_Requirements_Installer.bat and choose Run as administrator. Nothing has to be installed first. Ubuntu: open a terminal in the folder and run sudo bash ./Ubuntu_AI_Requirements_Installer.sh (24.04 recommended).

Afterwards the HTML report opens and logs.txt is saved next to the installer. Restart your PC and open a new terminal for the new PATH. You need this setup only once, not for every app. When the post shows a newer version, run the new one: finished parts are only checked, failed parts are repaired and components are updated, with backups first (--restore-env puts them back).

Tested for real: the tests compile and start C++ and CUDA programs, build Python and PyTorch-style CUDA extensions, compile GPU code for RTX 50 cards, encode a video and build a .NET app, in the environment a new terminal gets; the optional PyTorch GPU test runs with --torch-test. Supported: Windows 10 (21H2+) and 11; Ubuntu 22.04, 24.04 and 26.04 (desktop, server, cloud GPU, WSL2, Linux Mint, Zorin OS), 64-bit x86. Without an NVIDIA GPU everything still installs and compiling works; CUDA apps need an NVIDIA GPU.
