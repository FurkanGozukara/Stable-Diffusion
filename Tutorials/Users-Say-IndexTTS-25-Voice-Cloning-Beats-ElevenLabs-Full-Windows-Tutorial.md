Make your own voice speak words you never recorded. This complete IndexTTS 2.5 Windows tutorial starts with real generated speech, then takes you through a fresh installation, reference-based voice cloning, longer narration, expression controls, timed video, folder batches and training a voice from original recordings. Follow the actual local application from a short sample and script to saved audio and a trained voice setup.

You will learn how to find the current ZIP, locate it in Chrome, move it to a permanent folder and extract the whole package. Complete the linked Windows requirements first. Choose a path using English characters with no spaces, then run Windows_Install_or_Update.bat and Windows_Start_App.bat normally. Double-click the BAT files or select one and press Enter; do not run them as administrator. Keep the app command window open while you use its local browser interface. Load a clean voice reference, enter a short script, generate speech, play the complete result and find the output files. The reference can come from audio or video; use the range controls to choose the useful speech. Smart sentences groups longer scripts, while explicit pause tags and pronunciation dictionary entries help shape the result.

Main topics include speaker reference versus emotion reference, emotion vectors and text-driven expression, speaking rate and timing modes, candidate generation, saved outputs and reusable presets. Create a complete video from an SRT file and background image, with each caption tied to its intended time. Generate separate named audio files from a folder of scripts. For training, start with raw recordings and matching captions, prepare clips, audit the dataset and cache features. Keep entire source recordings separate for training, validation and the final test. Configure DoRA training, follow its loss and speech checks, inspect the saved checkpoint recommendation and compare Base with selected checkpoints using the same text, reference, strength and seed. The voice decoder has its own validation decision. A saved voice profile can carry reference, pace and decoding choices back into Voice Generation. Generate new words with the trained voice, inspect its line-length and pause guidance, and save the speaking rate for that adapter. Models and Performance covers GPU memory tiers, standard and INT8 ConvRot weights, block swapping, auxiliary model residency and the isolated memory benchmark. Model-file verification, unloading, Help, Changelog and the normal update route finish the Windows workflow.

Use the chapters to follow the installation in order or jump to voice cloning, expression, caption video, batches, training, checkpoint comparison and GPU memory controls.
